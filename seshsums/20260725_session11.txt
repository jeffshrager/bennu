- Built the manifest-driven bench runner:
  - New Lab/labrun.py: reads $EXPERIMENTS/<name>/manifest.json, validates
    it (hard error + difflib "did you mean" suggestion on unknown/typo'd
    keys, pin-role check that lamp=5/ozone=6 aren't swapped, setpoint vs.
    tickle-low-threshold consistency), refuses to run if the resolved
    experiment directory is at/under the repo root (the actual enforcement
    that data never re-enters the repo), then spawns Lab/o3.py and
    Lab/exprun.py as subprocesses with cwd set to the experiment directory.
    Supervises both at 1Hz for process death, o3.py's "RECOVERY abandoned"
    log line, and a >30s stall with no new READ line; shuts down via
    escalating SIGINT (10s) -> SIGTERM (5s) -> SIGKILL, then unconditionally
    forces GPIO pins 5 and 6 low via pinctrl with a logged readback. Writes
    run_record.json (resolved manifest + exact child argv + t0 + git rev +
    hostname) and runlog.tsv into the experiment directory. Supports
    --dry-run (validates and prints resolved commands + output layout,
    spawns nothing, touches no pins).
  - New Lab/example_manifest.json: the operator-facing manifest template.
  - Lab/o3.py: added --log-dir (defaults to the prior hardcoded
    <script_dir>/o3logs path, so standalone use is unchanged) — this was
    the actual blocker, since o3.py could not previously be told to log
    anywhere but inside the repo. Also GPIO.cleanup(args.gpiopin) instead
    of bare, and wrapped the control loop in except KeyboardInterrupt: pass
    (cosmetic — finally already drops the pin on SIGINT).
  - .gitignore: added Lab/o3logs/ and Lab/explog/ as a backstop for anyone
    still running o3.py/exprun.py by hand outside the runner.
  - Lab/exprun.py and Lab/annotate_tsv.py needed no changes — both already
    work correctly once the runner's cwd is the experiment directory.
