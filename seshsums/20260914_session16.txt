- Built shipat: a manual ship-position logger.
  - shiptrack/shipat_record.py: stdlib-only (argparse-free, just sys/
    datetime) helper. Takes ship, lat, lon as argv; validates lat in
    [-90,90] and lon in [-180,180]; reuses local_time.py's
    utc_offset_hours() (round(lon/15), clamped [-12,14]) rather than
    duplicating that logic. Prints one TSV row: ship, lat, lon, current
    UTC time (full date+time, "reported"), and ship local time (full
    date+time + UTC offset, same instant + offset).
  - shiptrack/shipat: bash script, `./shipat <ship> <lat> <lon>`.
    Resolves its own directory so it works regardless of caller's cwd.
    Creates shiptrack/ship-tracks.tsv with a header row if absent,
    appends the record via shipat_record.py, then tails the last 10
    lines of the file to stdout so the user sees the update in context.
    Made executable (chmod +x on both files).
  - Deliberately does NOT look up the ship name/MMSI in ships.json -
    ship is used exactly as given on the command line. Noted as a
    possible future step once arbitrary-ship lookup via the AIS API is
    sorted out.
  - Verified with `env -i` (no conda, plain system python3) that two
    successive calls correctly create-then-append to
    shiptrack/ship-tracks.tsv and each triggers a correct tail. Test
    rows (ship "RT" and "DISNEY DREAM" with made-up coordinates) were
    deleted afterward so no fabricated data would be committed - the
    real ship-tracks.tsv gets created fresh on the user's first real
    ./shipat call.
